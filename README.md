# PhotoPipe — Event-Driven Serverless Image Processing Pipeline

PhotoPipe is an event-driven, serverless cloud architecture built on Azure. It automatically processes uploaded images, generates metadata, and maintains an audit log of all blob storage activity using Azure Functions, Event Grid, and Azure Storage.
